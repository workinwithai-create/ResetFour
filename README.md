# ResetFour

Four-bar live reset desk for bedroom producers and AI-music finishers.

AI tools and loop DAWs keep the dense pocket going forever.
Session players write four live bars of stop-time and thin chairs — hats only, bass pedal, one hit, air — so the energy resets and the next section has a door.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight sample CDN pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.
No oscillators.
Audio never leaves the tab.
